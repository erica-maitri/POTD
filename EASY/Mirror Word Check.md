Problem Statement
Riya loves collecting words and arranging them in interesting ways. One day, she wrote a word on a piece of paper and wondered whether it reads the same from left to right and from right to left. Such words are called Mirror Words.

Help Riya determine whether the given word is a Mirror Word or not.

If the word reads the same in both directions, print YES; otherwise, print NO.

Input Format
A single string S containing only lowercase English letters.

Output Format
Print YES if the string is a Mirror Word.
Otherwise, print NO.

Constraints
1 ≤ |S| ≤ 100

Sample Testcase 0
Testcase Input
level
Testcase Output
YES
Explanation
The word "level" remains the same when reversed. Therefore, it is a Mirror Word.

Sample Testcase 1
Testcase Input
apple
Testcase Output
NO
Explanation
The reverse of "apple" is "elppa", which is different from the original word.
