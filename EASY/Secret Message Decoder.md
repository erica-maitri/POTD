Problem Statement
The Science Club of Greenwood School often exchanges coded messages during competitions and events. Each message contains a special code letter that helps club members identify important instructions.

Priya has been asked to organize all the messages before the next event. For every message, she needs to know how many times the designated code letter appears. Since the number of messages is large, manually counting the occurrences would take too much time.

To assist her, the club wants a program that can quickly analyze a message and report the total number of times the specified code letter occurs.

Given a message and a target character, determine the number of occurrences of that character in the message.

Input Format
First line contains string S.
Second line contains character C.

Output Format
Print a single integer representing the number of occurrences.

Constraints
1 ≤ Length of S ≤ 100

Sample Testcase 0
Testcase Input
BALLOON
L
Testcase Output
2
Explanation
Character L appears 2 times.

Sample Testcase 1
Testcase Input
MISSISSIPPI
S
Testcase Output
4
Explanation
Character S appears 4 times.
